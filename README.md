# Meenakshi Temple Website

A professional heritage website dedicated to the **Meenakshi Amman Temple, Madurai**, built as a Django web development project.

## About the Project

This website presents the temple's architecture, history, cultural significance, and visitor information through a modern and responsive digital experience.

The design combines traditional South Indian heritage elements with a clean, contemporary interface.

## Features

- Responsive design for desktop and mobile
- Cinematic temple hero section
- Temple architecture showcase
- Historical timeline
- About the temple section
- Contact and visitor information
- Google Maps integration
- Heritage-inspired typography and colours
- Responsive navigation
- Image-based visual sections

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- Bootstrap 5
- SQLite
- Google Maps Embed
